Lesson 3: A Short Computing Time Line


1: Abacus: An early counting tool used to help perform calculations.



2: Mechanical Calculator: A device designed to perform arithmetic more easily.



3: ENIAC: An early general-purpose electronic digital computer.



4: Transistor and Integrated Circuits: These smaller electronic components helped make computers more compact and efficient.



5: Personal Computer : Computer became more accessible for homes,schools,and offices.



6: Smartphone : A portable device that combines communication, computing,apps,and internet access.


Lesson 4: Labeled Parts of a Computer

A computer system uses different components to receive, process, display, and store information. These are the basic external parts of a desktop computer.

Monitor : An output device that display text,pictures, and other information.


System Unit : The case that contains important internal parts such as the CPU,memory, and storage drive.


Keyboard : An input device used to type letters,numbers,and commands.


Mouse : An input device used to move the pointer,click,and select items.
